# Model-weight terms and release checklist

`models/signlearn_model.keras` is included so reviewers can reproduce the local demo. The repository
code license does **not** automatically grant rights in the Google/Kaggle competition data or any
third-party source material from which the weights were derived.

Before publishing this repository, the maintainer should:

1. Re-read the current Google Isolated Sign Language Recognition competition rules while signed in.
2. Confirm that public redistribution of derived weights is allowed for the intended use.
3. Replace this notice with the exact model-weight license or remove the weights and publish an
   authorized download procedure.
4. Keep the dataset and third-party evaluation videos out of Git history.

Until this review is complete, treat the bundled weights as a research/demo artifact, not as a
commercially licensed model. This notice is not legal advice.
